# Бюджет по месяцам

Построим таблицу расходов: категории идут вниз, месяцы — вправо, формулы считают итоги по строкам и колонкам. Количество категорий и месяцев задаётся данными.

Для запуска нужна [установка пакета](../getting-started.md). В папке приложения создайте отдельную папку для этого примера:

```sh
mkdir budget-example
cd budget-example
```

## 1. Посмотрите шаблон

Скачайте [budget-template.xlsx](/examples/walkthroughs/budget-template.xlsx). На листе `Budget` всего одна строка категории и одна колонка месяца:

<div class="workbook-preview" tabindex="0" role="region" aria-label="Шаблон бюджета, A1:C12">

[![Шаблон: категории в A, месяц в B, итог категории в C. Строка данных — 7.](/images/example-budget-template.png)](/images/example-budget-template.png)

</div>

На изображении формулы показаны текстом. В скачиваемом XLSX это обычные формулы Excel.

| Область шаблона | Что повторяется |
| --- | --- |
| B2:B12, `{#months \| axis=columns}` | Вся колонка месяца: заголовок, суммы и нижний итог |
| A4:A10, `{#categories}` | Названия категорий вниз |
| B5:B9, `{#.amounts}` | Суммы текущего месяца вниз |
| C6:C8, `{#categories}` | Итог каждой категории вниз |

Все три вертикальных повтора содержат строку 7. Их маркеры стоят на разных строках: на строке маркера должен находиться только один структурный тег. При рендере строки маркеров исчезают, а значения остаются выровненными.

Два повтора `categories` берут один массив: первый выводит названия, второй — формулы итогов. `C7` содержит `=IFERROR(SUM(B7:B7),0)`. После раскрытия месяцев диапазон охватит все их колонки. `B11` содержит `=SUM(B3:B10)` и считает итог своего месяца.

## 2. Подготовьте данные

Сохраните [budget.data.json](/examples/walkthroughs/budget.data.json) рядом с шаблоном:

<<< @/public/examples/walkthroughs/budget.data.json

**Порядок `amounts` должен совпадать с порядком `categories`.** Это соответствие задаёт приложение. Для отсутствующей суммы оставьте `{}` на нужном месте: удаление элемента сдвинет следующие суммы к другим категориям.

В феврале у `Transport` значение `0`, а у `Books` значение отсутствует. Тег `{?.value}` разрешает отсутствие свойства и оставляет ячейку пустой. `SUM` складывает указанные числа.

## 3. Создайте отчёт

Скачайте [budget.ts](/examples/walkthroughs/budget.ts) в ту же папку:

<<< @/public/examples/walkthroughs/budget.ts

```sh
pnpm exec tsx budget.ts
```

Откройте `budget.xlsx` или скачайте [готовый результат](/examples/walkthroughs/budget.xlsx):

<div class="workbook-preview" tabindex="0" role="region" aria-label="Бюджет на три месяца и три категории, A1:E6">

[![Бюджет: январь 335, февраль 225, март 325, общий итог 885. Февральская сумма Books пустая, Transport равна нулю.](/images/example-budget.png)](/images/example-budget.png)

</div>

Итог `Food` — 725, `Transport` — 105, `Books` — 55. Общая сумма — **885**. Формула первой категории переместилась из C7 в E3 и стала `=IFERROR(SUM(B3:D3),0)`.

На изображении показаны пересчитанные значения. **Sheetbind переносит формулы, а вычисляет их Excel при открытии.** До пересчёта другой просмотрщик может показывать пустые значения.

## 4. Измените размер таблицы

- Добавьте категорию и соответствующий элемент в каждый `amounts` — появится строка.
- Добавьте объект в `months` с суммой для каждой категории — появится колонка.
- Для пустого списка категорий передайте `categories: []` и пустой `amounts` в каждом месяце. Заголовки месяцев и нулевые итоги останутся: [пример](/examples/walkthroughs/budget-0x3.xlsx).
- При `months: []` остаются названия категорий и нулевые итоги: [пример](/examples/walkthroughs/budget-3x0.xlsx). `IFERROR` обрабатывает исчезнувший диапазон сумм.

Этот пример создаёт отчёт. Для [редактируемой формы](./registration.md) используются повторения вниз; повтор колонок предназначен для отчётов.
