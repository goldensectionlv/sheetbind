# Учебный план

У человека несколько курсов, в каждом — свой список занятий. Выведем их одним документом с заголовками, примечаниями и итогом времени. У курсов будет ноль, одно и три занятия.

После [установки пакета](../getting-started.md#run-examples) создайте в приложении папку для примера:

```sh
mkdir study-plan-example
cd study-plan-example
```

## 1. Посмотрите шаблон

Скачайте [study-plan-template.xlsx](/examples/walkthroughs/study-plan-template.xlsx). Лист `Plan` содержит один курс с одной строкой занятия:

<div class="workbook-preview" tabindex="0" role="region" aria-label="Шаблон учебного плана, A1:C11">

[![Внешний повтор courses охватывает строки 3–9. Вложенный повтор lessons содержит строку 6. Под курсами находится общий итог.](/images/example-study-plan-template.png)](/images/example-study-plan-template.png)

</div>

На изображении формулы показаны текстом; в файле это формулы Excel.

| Ячейки | Назначение |
| --- | --- |
| B1 | `{learner}` — имя из корня данных |
| A2 и C10 | `{#courses}` и `{/courses}` — границы курса |
| A3:C3 | Объединённый заголовок `{.title}` текущего курса |
| A5 и C7 | `{#.lessons}` и `{/.lessons}` — занятия текущего курса |
| A6:C6 | `{.name}`, `{.minutes}`, `{?.note}` — поля занятия |
| A8:B8 | `Subtotal` и `=SUBTOTAL(9,B4:B7)` — время курса |
| A9:C9 | Объединённое примечание `{.note}` текущего курса |

После внутреннего повтора контекст снова относится к курсу: поэтому `{.note}` в A9 берётся у курса, а `{?.note}` в C6 — у занятия. Объединённые ячейки целиком помещаются в область курса и повторяются вместе с ним.

## 4. Проверьте итоги и пустой список

Промежуточные итоги — **0, 40 и 95 минут**, общий — **135**. `SUBTOTAL(9,...)` складывает числа. Диапазон курса включает текстовый заголовок `Minutes`: при пустом списке остаётся допустимый диапазон с нулевой суммой.

В B11 шаблона общий итог задан формулой:

```text
=IFERROR(SUBTOTAL(9,B3:B10),0)
```

После рендера она находится в B18 и охватывает B2:B17. Excel исключает вложенные `SUBTOTAL` из общего итога, поэтому время занятий не считается дважды. Подписи курсов и занятий на расчёт не влияют.

Изображение показывает значения после пересчёта. **Формулы вычисляет Excel, а не Sheetbind.** Проверьте значения после открытия файла.

Если передать `courses: []`, останутся имя и нулевой общий итог: [пример пустого плана](/examples/walkthroughs/study-plan-0.xlsx). Можно также скачать [один курс без занятий](/examples/walkthroughs/study-plan-1.xlsx).

Чтобы пользователь заполнял вложенные списки и приложение читало их обратно, перейдите к [регистрации участников](./registration.md).
