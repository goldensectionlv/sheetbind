# Sheetbind

Sheetbind заполняет XLSX-шаблоны данными. Вы готовите и оформляете книгу в Excel, приложение передаёт значения. Результат — отчёт или форма, которую пользователь может заполнить и вернуть.

Например, запишите в ячейку `{customer.name}` и передайте `{ customer: { name: 'Sample customer' } }`. В результате ячейка содержит `Sample customer`.

## С чего начать

1. [Первый отчёт](./getting-started.md) — установить пакет и получить один XLSX-файл.
2. [Шаблоны](./templates.md) — добавить повтор строк, итоги и вложенные данные.
3. [Проверки и списки](./fields.md) — проверять значения полей и предлагать варианты выбора.
4. [Заполнение формы](./forms.md) — выдать файл, изменить его в Excel и прочитать результат.

В инструкциях есть шаблоны для скачивания, код и ожидаемые результаты. Файлы примеров общие для обеих языковых версий.
