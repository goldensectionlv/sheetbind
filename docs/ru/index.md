# Sheetbind

Sheetbind заполняет XLSX-шаблоны данными. Вы готовите и оформляете книгу в Excel, приложение передаёт значения. Результат — отчёт или форма, которую пользователь может заполнить и вернуть.

## Из шаблона в отчёт

**Шаблон.** Одна строка товара между `{#items}` и `{/items}`. В ячейках стоят теги и формулы:

</div>

**Результат для трёх товаров.** Передаём `Paper`, `Pen` и `Folder` в массиве `items`. Получаем три строки с тем же оформлением:

<div class="workbook-preview" tabindex="0" role="region" aria-label="Готовая таблица товаров, колонки A–E">

[![Отчёт с товарами Paper, Pen и Folder на строках 3–5. Итог после пересчёта — 22.00.](/images/report-3.png)](/images/report-3.png)

Изображения показывают файлы примера: в шаблоне виден текст формул, в отчёте — значения после пересчёта. Sheetbind переносит формулы; вычисляет их Excel. Картинки можно открыть крупнее, а на узком экране — прокрутить по горизонтали.

[Разобрать пример: шаблон, JSON, код и готовый XLSX](./templates.md#report-example).
