# Excel и ограничения

Sheetbind читает незашифрованные шаблоны `.xlsx` и возвращает файлы `.xlsx`. Настройте оформление книги в Excel до импорта. Ниже описано, как её содержимое переносится при подстановке данных.

## Оформление и пустые ячейки

Шрифты, заливки, границы, выравнивание, числовые форматы, тема, высота строк и ширина колонок берутся из шаблона. Повторяемая область копирует своё оформление, включая оформленные пустые ячейки. Пустые ячейки с примечаниями, валидацией, условным форматированием и якорями рисунков также участвуют в размещении.

Содержимое рядом с повтором сохраняет занимаемые строки и колонки. Из-за этого между блоками разного размера может оставаться свободное место. Пустая на вид ячейка или промежуток сами по себе не создают отправленную запись; правила записей описаны в [чтении форм](./forms.md).

Объединение внутри повтора переносится вместе со своей копией. Объединение снаружи может растянуться на вставленные строки или колонки. Структурные теги размещайте вне объединённых ячеек по [правилам разметки областей](./templates.md).

## Формат ввода и тип значения

Формат отображения Excel не преобразует значение для Sheetbind. Строка `"12"` не проходит правило `number`, а число `12` — правило `string`.

| Ввод | Рекомендуемый формат | Результат чтения |
| --- | --- | --- |
| Количество или сумма | Числовой, например `0.00` | Число; формат не округляет сохранённое значение |
| Идентификатор с ведущими нулями | Текстовый (`@`), с правилом `string` | Строка, например `"001"` |
| Дата | Текстовый (`@`), ввод `2026-01-15` | Строка; проверку календарной даты при необходимости добавьте своим правилом |

Для полей формы с правилом `string` или выбором выдача заменяет формат `General` на текстовый. Явный формат исходной ячейки имеет приоритет, поэтому для дат и идентификаторов задавайте текстовый формат самостоятельно.

Встроенного типа даты нет. Нативная дата Excel в поле ввода возвращает ошибку `non-scalar`; обычный числовой номер даты без формата даты читается как число. Формула, введённая в поле ввода, возвращает ошибку `formula`. Формульные ячейки вне полей ввода в данные не попадают.

Длинные идентификаторы передавайте строками: числовая точность Excel может привести к потере цифр. Текст ячейки ограничен 32 767 кодовыми единицами UTF-16; символы, недопустимые в XML, отклоняются. Также действуют стандартные пределы XLSX по строкам и колонкам.

## Формулы и пересчёт

Записывайте формулы в обычные ячейки шаблона. Локальные ссылки на ячейки и диапазоны следуют размещению; ссылки внутри повторяемых формул относятся к соответствующей копии. Именованные диапазоны следуют перенесённым ячейкам и сохраняют область действия листа.

**Sheetbind не вычисляет формулы.** Библиотека запрашивает пересчёт Excel при открытии книги. До пересчёта другой просмотрщик может показывать пустое или устаревшее значение. Если итог нужен серверу сразу, вычислите его в приложении и передайте как данные.

Если повтор пуст и весь диапазон формулы исчезает, ссылка может превратиться в `#REF!`. Для итога, который должен стать нулём, включите фиксированную строку заголовка в диапазон `SUM` или явно обработайте отсутствие диапазона:

```text
=IFERROR(SUM(Amounts),0)
```

Для расчётов, которые должны разворачиваться вместе с повтором, используйте обычные ссылки A1. Для структурированных ссылок таблиц, ссылок на внешние книги, трёхмерных ссылок и других специальных выражений Excel правильный перенос при изменении размера повтора не гарантируется. Их исходное содержимое может сохраниться в файле без изменения всех ссылок. Внешние ссылки не загружаются.

Для формулы, которая берёт свойство выбранного объекта, [workbookChoiceRange](./api.md) возвращает имя созданного диапазона справочника.

## Нативные таблицы Excel

Таблица Excel не задаёт повтор Sheetbind. Библиотека переносит диапазон сохранённой таблицы, но не превращает её строки в записи шаблона и не интерпретирует все структурированные формулы таблицы.

Для повтора по данным преобразуйте нужную таблицу Excel в обычный диапазон, добавьте теги Sheetbind вокруг тела и используйте формулы по этому телу. Остальные таблицы можно оставить в книге. Проверьте их заголовки, итоги, диапазоны фильтров и формулы в готовом файле.

## Печать

Размер бумаги, ориентация, поля, масштаб и настройки страниц сохраняются из шаблона. Области печати и повторяемые строки заголовков следуют итоговым координатам, включая изменения при выдаче формы.

Sheetbind возвращает XLSX; разбиение на страницы и печать выполняет Excel. Проверьте предварительный просмотр после рендера с другим числом записей, особенно если на страницы влияют объединённые заголовки и высокие строки.

## Примечания, рисунки и диапазоны

| Содержимое | Как переносится |
| --- | --- |
| Примечания и гиперссылки | Адреса ячеек перемещаются или повторяются вместе со своей областью |
| Рисунки | Якоря перемещаются или повторяются вместе с областью; обе границы переносятся совместно |
| Нативная валидация и условное форматирование | Диапазоны следуют фактическим целевым ячейкам, включая пустые |
| Фильтры и сортировки | Охватывающий диапазон следует размещению; настройка удаляется, если её цель полностью исчезла |
| Именованные диапазоны | Локальные ссылки переносятся; полностью исчезнувшая ссылка становится `#REF!` |

Правило для отдельных групп ячеек может получить несколько диапазонов. Так валидация или заливка не распространяется на промежутки между копиями и скрытые границы формы. Формулы и фильтры, которым нужен один прямоугольник, используют охватывающий диапазон; он может включать ячейки между крайними точками.

Положение рисунка и ссылки на данные диаграммы — разные задачи. Сохранение диаграммы, рисунка или другой части XLSX не гарантирует перенос каждой вложенной формулы или расширения при повторении. Проверяйте эти возможности в приложении, которое будет открывать результат.

## Списки и существующая валидация

Sheetbind создаёт выпадающие списки Excel для [списков и выбора](./fields.md). Если исходная ячейка содержит только подсказку ввода, она сохраняется при добавлении списка.

Если в той же итоговой ячейке уже есть полноценное правило валидации Excel, рендер отклоняет конфликт с `RangeError`. Уберите нативное правило или список/выбор Sheetbind для этого поля. Два правила валидации одной ячейки не объединяются автоматически.

Проверка в интерфейсе Excel не заменяет чтение формы. Вставленные значения также нуждаются в проверке; `readWorkbookForm` разрешает выбор и выполняет объявленные правила полей.

## Проверка своей книги

Части исходного XLSX вне области адаптера сохраняются по возможности. Это не гарантия для произвольных расширений Excel, встроенных объектов и любого табличного приложения.

Для своего шаблона получите файлы с нулём, одной и несколькими записями. Откройте их в нужном табличном приложении и проверьте значения, формулы после пересчёта, расположение нативных объектов и предварительный просмотр печати. Для формы также отредактируйте и сохраните отдельный заполненный файл, затем прочитайте его с исходным шаблоном. Успешный рендер отчёта не проверяет этот путь редактирования и чтения.
