# Шаблоны

Шаблон — это XLSX-файл с тегами в ячейках. Подписи, оформление и формулы остаются в Excel. Теги выбирают значения из данных и задают области для повторения.

Это продолжение [первого отчёта](./getting-started.md). Выполняйте команды из папки приложения, где уже установлены Sheetbind, ExcelJS и `tsx`.

## Значения и пути

Ячейка поля содержит одну привязку и при необходимости её [директивы проверки или списка](./fields.md).

| Тег | Значение |
| --- | --- |
| `{customer.name}` | Свойство `name` объекта `customer` в текущем контексте |
| `{.name}` | Свойство `name` текущей записи |
| `{$root.customer.name}` | Путь от корневого объекта данных, в том числе внутри повтора |
| `{?customer.note}` | Поле может отсутствовать; в результате ячейка будет пустой |
| `{?.note}` | Поле `note` может отсутствовать в текущей записи |

Вне блока текущий контекст — корневой объект данных. В повторе это один элемент массива, в `with` — выбранный объект. `{name}` и `{.name}` выбирают одно свойство. Точка помогает увидеть обращение к текущей записи.

Например, для `{customer.name}` и `{?customer.note}` подходят данные:

```json
{
  "customer": {
    "name": "Sample customer"
  }
}
```

В ячейке имени будет `Sample customer`, ячейка примечания останется пустой. Без `?` отсутствие свойства вызывает `missing-source`. `null` даёт пустую ячейку; `0` и `false` сохраняют свои значения. Обычные поля принимают строки, конечные числа, логические значения и `null`. Для вывода объекта выберите его свойство или используйте [объектный выбор](./fields.md).

Путь состоит из имён свойств через точку. Теги не выполняют JavaScript: выражения `{price * quantity}` и `{items[0].name}` не поддерживаются. Вычислите значение в приложении или используйте формулу Excel.

Обычный текст остаётся как записан. В строку `Customer: {customer.name}` значение не подставляется. Вынесите подпись в соседнюю ячейку или подготовьте весь текст в данных. Чтобы вывести буквальный текст `{customer.name}`, запишите <code v-pre>{{customer.name}}</code>. К ячейке, начинающейся с привязки, нельзя дописать другой текст или вторую привязку.

## Повтор строк и итог

Соберём таблицу товаров с количеством, ценой, суммой и необязательным примечанием. Один шаблон даст отчёты для 0, 1 и 3 записей.

### Создайте шаблон

Скачайте [report-template.xlsx](/examples/tutorials/report-template.xlsx) или создайте лист `Order` с такими ячейками:

| Ячейка | Содержимое |
| --- | --- |
| A1 | `Customer` |
| B1 | `{customer.name}` |
| A2:E2 | Заголовки `Item`, `Quantity`, `Price`, `Amount`, `Note` |
| A3 | `{#items}` |
| A4 | `{.name}` |
| B4 | `{.quantity}` |
| C4 | `{.price}` |
| D4 | Формула `=B4*C4` |
| E4 | `{?.note}` |
| E5 | `{/items}` |
| A6 | `Total` |
| D6 | Формула `=SUM(D2:D5)` |

Сохраните файл как `report-template.xlsx`. Оформите строку 4 и задайте числовой формат `0.00` для цены и суммы. В локализованном Excel вводите формулы с именами функций своего приложения.

Два маркера задают прямоугольник:

- `{#items}` отмечает строку над телом и его крайнюю левую колонку.
- `{/items}` отмечает строку под телом и его крайнюю правую колонку.
- Здесь тело — `A4:E4`, включая пустые ячейки. Для каждой записи повторяется весь прямоугольник.

Каждый маркер должен быть единственным значением во всей своей строке. Закрывающий маркер находится ниже открывающего, в той же колонке или правее. Путь должен совпадать: `{#items}` закрывается тегом `{/items}`, а `{#.items}` — тегом `{/.items}`. Обе строки маркеров исчезают из отчёта.

Для блока высотой в несколько строк оставьте между маркерами все строки его тела. Пустые строки этого прямоугольника тоже повторяются. Объединённые ячейки и вложенные блоки должны помещаться внутри своего блока, не пересекая его границу.

Если повторяется только колонка A, проверьте закрывающий маркер: тег в A задаёт тело шириной в одну колонку. Перенесите его в E, если повторять нужно A:E.

### Передайте данные и запустите

Сохраните код как `report.ts` рядом с шаблоном, заменив скрипт из первого урока. Его можно также [скачать](/examples/tutorials/report.ts).

```ts
import { readFile, writeFile } from 'node:fs/promises'
import { importWorkbookXlsx, renderWorkbookReport } from 'sheetbind'

const template = await importWorkbookXlsx(await readFile('report-template.xlsx'))
const items = [
  { name: 'Paper', quantity: 2, price: 5 },
  { name: 'Pen', quantity: 0, price: 3, note: 'Spare' },
  { name: 'Folder', quantity: 3, price: 4 },
]

for (const count of [0, 1, 3]) {
  const data = { customer: { name: 'Sample customer' }, items: items.slice(0, count) }
  await writeFile(`report-${count}.xlsx`, await renderWorkbookReport(template, data))
}
```

```sh
pnpm exec tsx report.ts
```

Полные входные данные есть и в JSON: [0 записей](/examples/tutorials/report-0.json), [1 запись](/examples/tutorials/report-1.json), [3 записи](/examples/tutorials/report-3.json).

### Проверьте результат

Откройте три файла из папки приложения:

| Файл | Строки товаров в Excel | Ячейка итога | Итог после пересчёта |
| --- | --- | --- | --- |
| `report-0.xlsx` | Нет | D3 | 0 |
| `report-1.xlsx` | Строка 3 | D4 | 10 |
| `report-3.xlsx` | Строки 3–5 | D6 | 22 |

`items: []` убирает тело повтора. Отсутствие `items` — ошибка: повтор ожидает массив объектов. Нулевое количество у `Pen` остаётся нулём.

Формула итога включает заголовок и тело. `SUM` пропускает текст заголовка, поэтому в пустом отчёте остаётся допустимый диапазон. Sheetbind переносит ссылки формул, но не вычисляет результат. Excel пересчитывает при открытии; другой просмотрщик до пересчёта может показать пустое или устаревшее значение. Поддержка формул описана в разделе [«Excel и ограничения»](./xlsx.md).

## Если книга уже есть

Работайте с копией файла. Для таблицы выше возьмите [ordinary.xlsx](/examples/tutorials/ordinary.xlsx):

| Строка | A | B | C | D | E |
| --- | --- | --- | --- | --- | --- |
| 1 | Customer | Sample customer | | | |
| 2 | Item | Quantity | Price | Amount | Note |
| 3 | Paper | 2 | 5 | `=B3*C3` | |
| 4 | Total | | | `=SUM(D2:D3)` | |

1. Замените B1 на `{customer.name}`.
2. Вставьте целую пустую строку перед товаром и запишите `{#items}` в A3.
3. Вставьте целую пустую строку между товаром и итогом и запишите `{/items}` в E5. Остальные ячейки обеих строк маркеров оставьте пустыми.
4. Замените A4, B4, C4 и E4 на `{.name}`, `{.quantity}`, `{.price}` и `{?.note}`.
5. Проверьте формулы: в D4 — `=B4*C4`, в D6 — `=SUM(D2:D5)`.
6. Сохраните файл как `report-template.xlsx` и запустите `report.ts` выше.

Если в книге несколько примерных товаров, оставьте один как тело повтора, остальные удалите из копии шаблона. Сохраните его оформление. Перенесите закрывающий маркер правее, если к товару относятся дополнительные колонки. Проверьте в Excel получившиеся значения, формулы и используемые возможности книги.

Sheetbind принимает уже размеченный файл. Это инструкция по редактированию: автоматического превращения произвольной книги в шаблон нет.

## Объектный блок `with`

Используйте `with`, чтобы не повторять длинный путь к объекту. Он меняет текущий контекст, тело при этом не повторяется.

| Ячейка | Содержимое |
| --- | --- |
| A1 | `{#with customer}` |
| A2 | `Name` |
| B2 | `{.name}` |
| A3 | `City` |
| B3 | `{.address.city}` |
| B4 | `{/with}` |

```json
{
  "customer": {
    "name": "Sample customer",
    "address": { "city": "Oslo" }
  }
}
```

После удаления строк маркеров имя и город окажутся в B1 и B2 отчёта. `with` ожидает объект и всегда закрывается тегом `{/with}`. Для обращения вне выбранного объекта используйте `{$root.some.path}`.

В большем примере объектный блок сочетается с повторением строк работ: [шаблон](/examples/regions/template.xlsx), [данные](/examples/regions/template.data.json).

## Вложенные повторы

Поместите один целый блок внутрь другого. Каждый внутренний массив берётся из текущей внешней записи.

| Ячейка | Содержимое |
| --- | --- |
| A1 | `{#groups}` |
| A2 | `{.name}` |
| A3 | `{#.items}` |
| A4 | `{.name}` |
| B4 | `{.quantity}` |
| B5 | `{/.items}` |
| B6 | `{/groups}` |

```json
{
  "groups": [
    {
      "name": "Office",
      "items": [{ "name": "Paper", "quantity": 2 }, { "name": "Pen", "quantity": 0 }]
    },
    { "name": "Storage", "items": [] }
  ]
}
```

В отчёте будут `Office`, два его товара, затем `Storage`. Пустой внутренний массив убирает только тело с товарами; название группы остаётся. Открывающий и закрывающий маркеры внутреннего блока должны помещаться в прямоугольник внешнего.

Можно скачать больший [вложенный шаблон](/examples/regions/nested.xlsx) и его [данные](/examples/regions/nested.data.json).

## Повтор колонок

Добавьте `axis=columns`, чтобы повторять тело вправо. Маркеры по-прежнему стоят над исходным прямоугольником и под ним:

| Ячейка | Содержимое |
| --- | --- |
| A1 | `{#offers \| axis=columns}` |
| A2 | `{.name}` |
| A3 | `{.price}` |
| A4 | `{/offers}` |

```json
{
  "offers": [
    { "name": "Option A", "price": 10 },
    { "name": "Option B", "price": 12 },
    { "name": "Option C", "price": 9 }
  ]
}
```

Тело — `A2:A3`. В отчёте названия займут A1:C1, цены — A2:C2. Чтобы повторять блок шире одной колонки, поставьте закрывающий маркер в его последнюю колонку. Ширину колонок задавайте в Excel.

Повтор колонок работает в отчётах. Редактируемые формы поддерживают повтор строк. В [шаблоне сравнения](/examples/comparison/template.xlsx) и его [данных](/examples/comparison/template.data.json) показан отчёт с обоими направлениями повторения.

## Запуск дополнительных примеров

JSON-файлы примеров областей и сравнения содержат свойство `data`. Сохраните нужную книгу как `template.xlsx`, её JSON — как `template.data.json`, затем используйте такой `report.ts`:

```ts
import { readFile, writeFile } from 'node:fs/promises'
import { importWorkbookXlsx, renderWorkbookReport } from 'sheetbind'

const template = await importWorkbookXlsx(await readFile('template.xlsx'))
const { data } = JSON.parse(await readFile('template.data.json', 'utf8'))
await writeFile('report.xlsx', await renderWorkbookReport(template, data))
```

Выполните `pnpm exec tsx report.ts` и откройте `report.xlsx`. Во [вложенном примере](/examples/regions/nested.data.json) три площадки с 0, 1 и 3 работами. В [примере сравнения](/examples/comparison/template.data.json) три товара и три предложения; отсутствующая цена остаётся пустой.
