# Участие в разработке

[English](./CONTRIBUTING.md) | [Русский](./CONTRIBUTING.ru.md)

Используйте версии Node.js и pnpm из `package.json`. Установите зависимости через `pnpm install --frozen-lockfile`; перед отправкой изменений публичного API или XLSX запустите `pnpm check:release`.

Публичная точка входа — `sheetbind`. Привязки и проверка данных находятся в `src/core`, модель книги и размещение — в `src/grid`, записи форм — в `src/form`, работа с файлами — в `src/xlsx`.

Используйте нейтральные синтетические примеры. Проверяйте XLSX после экспорта и открытия независимым потребителем; вывод отчёта сам по себе не проверяет чтение формы. Поддерживайте документацию на [английском](./docs/development.md) и [русском](./docs/ru/development.md) синхронно. Несовместимые изменения API записывайте в `CHANGELOG.md`.
